# Wee Spurts — Open Questions

Questions that **cannot be answered on paper** — only the prototype can settle them. Do not make permanent design decisions on these topics until we have hands-on evidence.

## Q1. What is the actual differentiator?

**Hypothesis:** The "table talk" loop (betting on and heckling each other between turns) layered on chaotic physics is what makes this fun and distinct.

**How to answer:** Build bowling + slop layer. Play it with Braeden. Did you laugh *because of* the bets and taunts, or despite them?

**Status:** ❓ Open — prototype required.

## Q2. How far can the "drinking" gimmick go on Steam?

Steam's content rules and age-rating thresholds for alcohol references need to be verified before store submission.

**How to answer:** Review Steam's content guidelines, check comparable titles (e.g., Pummel Party, Jackbox), consult Valve's developer docs.

**Status:** ❓ Open — revisit before store submission.
