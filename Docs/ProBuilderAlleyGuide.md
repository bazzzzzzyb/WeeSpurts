# Blocking Out the Alley with ProBuilder

A beginner guide to greyboxing the bowling-alley *environment* (the room + social spaces) inside
Unity using ProBuilder. macOS shortcuts noted; on Windows swap ⌘ for Ctrl.

> **Scope note.** The playable **lane, pins, and ball are generated by code**
> (`GreyboxSceneBuilder`) — do NOT rebuild those in ProBuilder. This guide is for blocking out
> the *building around* the lane: walls, floor, ceiling, and the walkable social space (bar +
> slots corner, seating, spectator area) that `OpenQuestions.md` flags as a possible
> differentiator. Greybox only — flat colors, no detail. Art dressing comes later (`ContentPlan.md`).

---

## 1. Install ProBuilder (one time)
1. `Window > Package Manager`.
2. Top-left dropdown → **Unity Registry**.
3. Search **ProBuilder** → **Install**. (Optionally also install **Polybrush** for scattering props later.)
4. Open the toolbar: `Tools > ProBuilder > ProBuilder Window`. Dock it somewhere handy.
   *(Exact menu location can vary slightly by Unity version — if it's not under Tools, check the `Window` menu.)*

## 2. Turn on grid snapping (do this before building anything)
Blocking out is 10x easier when everything snaps to a grid.
- In the Scene view toolbar, find the **grid snapping** toggle (magnet icon) and turn it on.
- Set a grid size of **0.5 m** to start (small enough for detail, big enough to stay tidy).
- While moving/scaling an object, **hold ⌘** to snap to the grid.
- Work in the **top and side views** (press the axis gizmo cone in the top-right of the Scene view) — blocking out is much more precise from a straight-on angle than a free 3D view.

## 3. Learn the 4 edit modes (this is 80% of ProBuilder)
With a ProBuilder object selected, you switch what you're editing:
- **Object** — move/rotate/scale the whole shape (normal Unity gizmos, `W`/`E`/`R`).
- **Vertex** — drag corner points.
- **Edge** — drag/loop edges.
- **Face** — select a face and **Extrude** it (pull it out into new geometry) — this is how you turn a box into a room.

Toggle modes from the ProBuilder toolbar (or the little floating mode bar in the Scene view).

## 4. Block out the alley shell
1. In the ProBuilder window click **New Shape**, choose **Cube**, and drag out a big flat box for the **Floor** — size it to comfortably contain the existing lane plus walking room on both sides and behind the throw line. Snap it to grid.
2. New Shape → Cube for each **Wall**. Make them thin and tall; snap them to the floor edges. Four walls = the room.
   - *Faster alternative:* select the floor, switch to **Face** mode, select the top face, and **Extrude** upward to pull up walls — then delete the inner faces you don't need. Either works; do whichever clicks for you.
3. Add a **Ceiling** (another cube, or extrude the walls inward). Leave it off at first if the top-down view feels cramped — you can add it once the layout's set.
4. **Name everything clearly** (`Floor`, `WallLeft`, `Ceiling`…) and keep them under one empty parent GameObject called `AlleyGreybox` so the room is one tidy group separate from the code-spawned lane.

## 5. Block out the social space (the walkable-alley test)
Rough volumes only — you're testing *layout and flow*, not making furniture:
- **Bar corner** — a low box for the counter + a taller box behind it. This is the "grab a beer" spot from the pitch.
- **Slots corner** — two or three upright boxes as machine stand-ins.
- **Seating / spectator area** — a couple of low boxes behind the throw line where players wait and heckle.
- **Approach / throw area** — leave clear floor where the code-spawned lane begins.

Walk a placeholder capsule through it (or your future character) and ask: does moving between turns feel fun, or annoying? That's the whole point of blocking it out.

## 6. Greybox materials
- Make a few flat-color materials (grey floor, lighter walls, one accent color for the bar/slots so they read at a glance). You can reuse the greybox materials the scene builder already creates.
- Assign a material by selecting faces in **Face** mode and clicking the material — or just per-object in the Inspector. Don't fuss; greybox is about *shape reading*, not looks (`ArtGuide.md` silhouette rule applies).

## 7. Save + version-control notes
- Save as its own scene (e.g. `Assets/_Project/Scenes/AlleyGreybox.unity`) **or** build it into the bowling scene — your call, but decide before you start so you're not merging two.
- ProBuilder meshes serialize **into the scene file**. Per `CodingStandards.md`, scenes are the #1 two-person merge hazard — **one owner per scene at a time.** Coordinate with Braeden; don't both edit the alley scene at once.
- Commit with Git LFS active (already set up).

## 8. When to stop
Stop the moment the layout answers "is the walkable space fun?" — don't detail it. If it *is* fun, the real art pass (Synty/Kenney props, lighting) is a later scheduled stage, not now. If it isn't, you just saved yourself weeks by finding out in grey boxes.

---

### Quick reference
| Want to… | Do this |
|---|---|
| Make a shape | ProBuilder window → **New Shape** |
| Turn a box into a room | **Face** mode → select top face → **Extrude** |
| Move precisely | Grid snapping on, hold **⌘** while dragging |
| Edit a corner/edge | **Vertex** / **Edge** mode |
| Color a wall | **Face** mode → select → assign material |
| Keep it tidy | Parent everything under an `AlleyGreybox` empty |
