## Starting free sources
- **Kenney.nl** — thousands of CC0 low-poly models, UI, audio. No attribution required. Best first stop.
- **Unity Asset Store** — filter to Free; check the license per asset.
- **Mixamo** — free rigged character animations (needs a humanoid rig).

## Rules
- Log EVERY asset here with its license before committing it. A Steam release can be blocked by one improperly-licensed file.
- Keep large source files (`.psd`, `.blend`, raw `.wav`) tracked via Git LFS.
