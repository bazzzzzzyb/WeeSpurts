# Wee Spurts

A chaotic online party game for Steam — Wii Sports energy with a friendslop twist: funny physics, yelling at your friends, fake gambling, and a (satirical) drinking gimmick. First minigame: **Bowling**. Built by Tony + Braeden with Claude Code as the engineering team.

## Start here

1. **`BLUEPRINT.md`** — the master plan: market research, direction, phases and gates, how to work.
2. **`CLAUDE.md`** — auto-loaded by Claude Code; the rules of engagement.
3. **`Docs/`** — the Game Bible and system docs. Docs are law: if code and Bible disagree, the Bible wins.

## Repo map

- `Docs/` — GameBible, Roadmap, Networking, UI, ArtGuide, CodingStandards, DefinitionOfDone, OpenQuestions, Marketing
- `.claude/` — agents (your five AI specialists) and commands (`/build-system`, `/qa-review`)
- `Unity/` — the Unity project (create it here via Unity Hub, latest LTS)
- `Assets/` — source art/audio + the asset/license log (not Unity's internal Assets folder)
- `Docs/archive/` — the old chat-paste persona workflow, retired

## The workflow, in one sentence

> Tony decides *what's fun and what ships*; Claude Code builds one system at a time, always grounded in the Bible.
