# /Unity

The Unity project goes here.

When you create it in Unity Hub, point the project location at this folder so the path is `WeeSpurts/Unity/`. Unity will generate its own `Assets/`, `Packages/`, and `ProjectSettings/` inside here — those DO belong in git (except the ignored folders listed in the root `.gitignore`).

Do not confuse Unity's internal `Assets/` (compiled game assets, keep in git) with the repo-level `/Assets` folder at the root (source files + asset-pack notes).
